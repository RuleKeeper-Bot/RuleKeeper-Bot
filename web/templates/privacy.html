Privacy Policy

Last updated: October 19, 2025

RuleKeeper is an open-source Discord bot designed to assist with moderation, leveling, music playback, server backups, and customization for Discord servers. Your privacy is important to us. This policy outlines what data RuleKeeper collects, how it's used, and your rights.

1. Data Collected

RuleKeeper stores the following types of data to provide its features:

User Data

  • User IDs: Discord user IDs for identifying users across features.
  • Level & XP Data: Experience points, levels, message counts, voice activity time, and XP boosts for the leveling system.
  • Music Playlists: User-created playlists including track URLs and metadata.
  • Birthday Information: Birth dates (month/day/year) if voluntarily provided via birthday commands.
  • Warning Records: Moderation warnings issued to users, including timestamps and reasons.

Server Configuration Data

  • Server IDs, Channel IDs, Role IDs: For configuring features per server.
  • Custom Commands: User-defined commands, their responses, and permissions.
  • Logging Settings: Configuration for which events to log and where.
  • Moderation Settings: Auto-moderation rules, spam detection thresholds, blocked words, warning actions.
  • Welcome/Goodbye Messages: Custom messages and channel assignments.
  • Level System Settings: XP rates, level-up rewards, role assignments.
  • Crafty Controller Integration: Minecraft server configurations, API tokens, server IDs.
  • Backup Schedules: Server backup configurations and scheduled backup times.

Moderation & Event Logs

  • Moderation Actions: Records of warnings, kicks, bans, timeouts, and who issued them.
  • Event Logs: Server events such as member joins/leaves, message edits/deletions, role changes (when logging is enabled).
  • Spam Detection Data: Temporary message history for detecting spam patterns.

Backup Data

  • Server Backups: Channel structures, role configurations, permissions (stored as JSON files).
  • Backup Metadata: Timestamps, creator information, restoration history.

Note: RuleKeeper does not store message content unless explicitly configured for moderation logging. Message IDs and metadata may be stored temporarily for spam detection.

2. How Data Is Used

  • Feature Delivery: To provide moderation, leveling, music playback, backups, and custom commands.
  • Server Management: To maintain server-specific configurations and preferences.
  • Analytics: To track XP progression, level rankings, and user engagement (server-specific only).
  • Security: To detect and prevent spam, abuse, and rule violations.
  • Diagnostics: For debugging and troubleshooting when issues occur.

3. Data Storage & Security

  • Storage Location: All data is stored in a local SQLite database by the bot host.
  • Retention: Data is retained as long as the bot remains in your server or until manually deleted.
  • Security: Database files are protected with file system permissions and encrypted connections where applicable.
  • No Third-Party Sharing: Your data is never sold, shared, or provided to third parties.
  • Self-Hosted Instances: If you self-host RuleKeeper, you are solely responsible for data security and compliance with applicable laws.

4. User Rights

If you're a server admin:

  • You can view, modify, or delete your server’s data via the dashboard.
  • You can remove the bot at any time, which stops all data collection.

If you're a regular user:

  • You can visit the data deletion page to request deletion of any stored data related to you.

5. Self-Hosting

If you run your own instance of RuleKeeper, you're responsible for complying with data laws applicable to your region and users.
